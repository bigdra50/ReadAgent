# ReadAgent 要件定義

> このドキュメントが仕様の一次情報です。実装・レビュー・PR はここの節番号を参照します。
> 変更するときは、実装より先にここを直してください。

## 1. コンセプト

技術書などのPDFを読みながら、気になった箇所を選択して Claude Agent と深掘りでき、
対話内容が自動で読書ノートに反映されるツール。

全文をAIに渡すのではなく、**選択範囲を起点にエージェントがツールを使って調査・整理する**
「エージェント寄り」の読書体験を目指す。

## 2. 技術前提

- **言語**: TypeScript
- **AI**: Claude Agent SDK（`@anthropic-ai/claude-agent-sdk`）
- **認証**: Claude サブスクリプション利用を前提（APIキー課金は任意の代替手段）
- **実行形態**:
  - 第1優先: ローカル完結
  - 将来: Webサーバー化も検討可能な設計
- **方向性**: 単純チャットではなくエージェント寄り（ツール利用を積極的に活用）

## 3. 主要機能

### 3.1 書籍表示・選択

- PDFの読み込み・テキスト抽出・表示
- 目次サイドバー
- テキスト選択＋ハイライト
- 選択範囲のテキストと位置情報をエージェントに渡す

### 3.2 エージェント機能

- 選択箇所を起点にした深掘りチャット
- ストリーミング応答
- ツール利用例:
  - WebSearch / WebFetch（関連情報の補完）
  - Read / Glob / Grep（周辺文脈の参照）
  - 図解生成（Mermaid など）
  - カスタムツール（ノート更新など）
- セッション管理（選択箇所ごと or 継続セッション）
- ツール実行状況の可視化

### 3.3 読書ノート機能

- **形式**: Markdown（`.md`）
- **更新タイミング**: オプション化
  - `agent`（デフォルト）: エージェントが判断して更新
  - `always`: 毎回必ず更新
  - `manual` など、その他も拡張可能
- **粒度**: オプション化（`per-question` / `per-section` / `free` / `summary`）
- **動作**:
  - バックグラウンドで非同期実行（読書・チャットをブロックしない）
  - エージェントがカスタムツール経由でノートを更新
- **内容例**: 引用原文、質問、回答、図解、関連リンク、タグ、タイムスタンプ
- **永続化**: ローカルファイル（書籍単位）
- **双方向リンク**: ノート ↔ 本文の選択箇所・チャット履歴

### 3.4 設定の階層（CLAUDE.md 的）

優先順位（後勝ち）:

1. グローバル設定
2. プロジェクト設定（書籍単位）
3. スコープ設定（章・セッション・一時上書き）

設定例: `updateMode` / `granularity` / その他ノート関連オプション

実装: `packages/core` の `resolveNoteConfig`。

## 4. UI要件

- **基本レイアウト**: リサイズ可能な分割ビュー（Split View / Multi-pane）
- **参考**: Apple HIG Split Views、Material Design 3 Panes
- **ペイン構成例**: 左＝目次 / 中央＝本文 / 右＝チャット・読書ノート（切り替え or 追加分割）
- **適応**:
  - 広い画面 → 複数ペイン同時表示
  - 狭い画面 → スタック・オーバーレイ・非表示にフォールバック
- **ノートアクセス**:
  - 常時アクセス可能（ヘッダーアイコン＋ショートカット）
  - 更新中でもシームレスに開ける
  - 更新状態を控えめに可視化（バッジ・スケルトンなど）
- ペインの個別表示/非表示、リサイズ可能

## 5. 非機能要件

- サブスク利用枠を意識したコンテキスト管理（全文投入をしない）
- バックグラウンド処理の安定性・キャンセル可能性
- エラーハンドリング（ツール失敗時のフォールバック）
- ローカル完結と将来のWebサーバー化を両立する抽象化

## 6. 実装フェーズ

| Phase | 内容 |
| --- | --- |
| 1 (MVP) | PDF表示 + テキスト選択 + 基本エージェント応答 + ストリーミング |
| 2 | ツール追加 + 読書ノートの基本自動更新（バックグラウンド） |
| 3 | ノートUI（分割ビュー連携）・設定階層・双方向リンク |
| 4 | 複数書籍対応・高度な整理・Webサーバー化検討 |

現在地とタスク分解は @roadmap.md を参照。
