# 画面写真について

README とドキュメントに貼っている画像の撮影条件。

## 撮影時の状態

- **エージェントの応答は差し替えている。** 実際の Claude サブスクリプション認証を
  通した確認ができていないため、回答・まとめ・図の文面はすべてダミー
- 書籍も撮影用のサンプル2冊（`Tracing JIT` / `型システム入門`）で、実データではない
- 画面幅は 1280x820。`narrow.png` だけ 720x820

つまり**画面の構造とやり取りの流れは本物、文字の中身は作り物**として見てほしい。

## 撮り直すとき

UI が変わったら撮り直す。撮影は Playwright でサーバーとUIを立ち上げて行った。
スクリプトはリポジトリに含めていない（使い捨てのため）。
再現に必要なのは上の「撮影時の状態」だけで、特別な手順は無い。
