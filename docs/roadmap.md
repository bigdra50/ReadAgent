- [x] Mermaid の描画（図が現れたときだけ動的に読み込む）

### 保留した判断

- **granularity の構造的な意味**: 要件は `per-question` / `per-section` / `free` /
  `summary` の値を挙げているが、それぞれがノートの構造をどう変えるかは定義していない。
  いまはエージェントへの書き方の指示として渡すだけにしてある。
  実際に読み返してみて、節単位の統合などが要ると分かってから構造を足す
